# Real-device acceptance

Use [build guide step 6](BUILD_GUIDE.md) for the current first-run sequence and [hardware wiring](HARDWARE.md) before applying power. Never factory-reset an existing stick just for ordinary reconnection.

Record phone/app/firmware versions, mount angle and measured conditions. Verify:

- Fresh real telemetry/camera; calibrated range, orientation and battery readings.
- Local motor warnings with phone/internet disconnected; sensor faults remain unknown.
- Google login completes once; scene analysis and Maps work with App Check enabled.
- User/Guardian pairing, notification delivery and remote features on separate networks.
- Navigation/audio interruption, reconnect, screen-off/return and saved distance after restart.
- SOS through an informed test contact; distinguish actual delivery from an opened composer.

Begin walking with a sighted companion, normal mobility aid and controlled level ground. Test misses, false warnings, latency and power stability before expanding conditions. Gaps in GPS cannot reconstruct unmeasured distance. Camera/sonar cannot certify side clearance, stairs, drop-offs or crossing safety. Passing software tests does not establish physical safety certification.
